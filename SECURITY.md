# Politique de sécurité

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité.

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**.

Merci d'indiquer :
- la version ou le commit concerné ;
- les étapes pour reproduire le problème ;
- l'impact estimé.

Vous recevrez un accusé de réception dès que possible ; la correction sera publiée avant toute divulgation détaillée.

## Versions supportées

Le projet est en cours de développement : seule la dernière version publiée reçoit des correctifs de sécurité.

## Périmètre

Sont concernés : l'authentification, les rôles, l'isolation des données entre utilisateurs, les envois de fichiers et la configuration du conteneur.
